# illness-death
Method for estimating the cumulative incidence rate (CIF) of disease in the illness-death model.
Reference: Gorfine M, Zucker DM, and Shoham S. (2025). Cumulative incidence function estimation based on population-based biobank data. Biometrics, Volume 81, Issue 3, September 2025, ujaf049, https://doi.org/10.1093/biomtc/ujaf049
This Github site contains R code used for carrying out the simulation study in the paper.
The site also includes the full simulation results.
